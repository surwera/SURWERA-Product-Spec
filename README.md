# SURWERA Product Spec

Product specification website for SURWERA.

## Quick Start

**View the website:**
```bash
open index.html
```

**View the one-pager:**
```bash
open one-pager.html
```

## Export to PDF

Generate a PDF from the one-pager (requires Google Chrome):
```bash
./export-pdf.sh
```

## Structure

- `index.html` — Main product spec website
- `one-pager.html` — Single-page summary
- `content/` — Images and media assets
- `styles.css` / `print.css` — Styling
